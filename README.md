# 강의를 통해 학습을 해보자!

강의는 기본적으로 내용을 보다 쉽게 이해할 수 있다.
도서: 시각 + 촉각(선택) 정보로 상세한 내용
강의: 시각 + 촉각(선택) + 청각 정보로 조금 더 이해하기 쉬움

이전까지도 강의 학습은 많이했지만, 앞으로 조금 더 자세한 정리를 위해
해당 repository에서 관리한다.

이전까지 학습한 내용은 [🔗여기](https://github.com/learn-lecture/learn)에 대충 정리 되어있다.
